# PHANTASM'27 presents VAAGAI 2K26

Official website for the Department of Mechanical Engineering, Government College of Engineering, Bargur.

**Event:** Vaagai 2k26 / PHANTASM'27  
**Date:** 17–18 September 2026  
**Venue:** Government College of Engineering, Bargur, Krishnagiri  

## GitHub Pages

This repository is a static HTML/CSS/JavaScript website and can be hosted directly with GitHub Pages.

## Updating the website

- Main page: `index.html`
- Styles: `assets/style.css`
- Interactions: `assets/script.js`
- Images and logos: `assets/`

When the Google Form is ready, replace the registration placeholder inside the `#register` section of `index.html` with the Google Form iframe.

## Collaboration

Keep `main` as the published branch. For larger changes, create a feature branch and open a pull request so multiple collaborators/Claude accounts can work without overwriting each other's changes.
