# Vaagai 2k26 — Site Status

## Current architecture
- `index.html` — main landing page
- `events.html` — event catalogue and details
- `rules.html` — rules and guidelines
- `schedule.html` — 17–18 September schedule
- `registration.html` — live Google Form registration
- `assets/` — logos, poster, styles and scripts

## Design direction
Tamil cultural / temple-inspired visual identity combined with Mechanical Engineering motifs. Synerix26 is used only as an information-architecture reference, not as a visual template.

## Registration
Google Form is embedded on `registration.html`. Changes made in Google Forms do not require a website rebuild.

## Editing workflow
All source is public in GitHub. Other Claude accounts can work from the same repository after being given access to the repository/project context.
