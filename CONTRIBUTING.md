# Vaagai 2k26 — collaboration guide

This repository contains the public website for **PHANTASM'27 presents Vaagai 2k26**, Department of Mechanical Engineering, Government College of Engineering, Bargur.

## Working with another Claude account

All website source is stored in this repository. A different Claude account can continue the project by connecting to this same GitHub repository and working from the `main` branch.

Before making changes:

1. Open the repository and confirm you are working on `main` or a dedicated branch.
2. Inspect the existing HTML and assets before replacing anything.
3. Make one logical change at a time.
4. Commit with a descriptive message.
5. Check the GitHub Pages site after the commit.

## Important files

- `index.html` — main landing page
- `events.html` — event catalogue and details
- `rules.html` — participant rules
- `schedule.html` — programme/schedule
- `registration.html` — Google Form registration page
- `assets/style.css` — main site stylesheet
- `assets/site-shell.css` — shared Vaagai shell layer
- `assets/theme-foundation.css` — design tokens and accessibility foundation
- `assets/navigation.css` — navigation enhancement styles
- `assets/script.js` — navigation, tabs, reveal animation and footer year
- `assets/poster-web.jpg` — web version of official poster

## Content updates

Event rules, fees, venues, prize amounts and schedule details may change. Treat the latest organiser-provided information as authoritative. Do not invent missing event details.

The registration form is hosted by Google Forms. Changes to questions/options should normally be made in Google Forms rather than in the website source.

## Design direction

The visual identity should represent Tamil cultural/architectural heritage without copying another site's theme. Current direction uses deep maroon, antique gold, warm ivory and restrained architectural details.

Keep the site responsive, accessible, fast-loading and usable on mobile.
